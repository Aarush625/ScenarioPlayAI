# 🎭 Scenario Play AI

An interactive role-play AI application that lets you create and play out any scenario with a character powered by Groq's LLM. Perfect for storytelling, creative writing, or just having fun conversations with custom personalities.

## ✨ Features

- 🎭 **Custom Scenarios** - Create any character or situation you can imagine
- 💬 **Real-time Chat** - Seamless conversation with AI responses
- 📜 **Chat History** - All conversations are automatically saved
- 🔄 **Load Previous Chats** - Pick up where you left off anytime
- 🗑️ **Delete Conversations** - Manage your chat history
- 🎨 **Dark Mode UI** - Easy on the eyes for long roleplay sessions
- 📱 **Responsive Design** - Works on desktop and mobile
- ⚡ **Fast Responses** - Powered by Groq's ultra-fast inference

## 🚀 Quick Start

### Prerequisites

- Node.js (v18 or higher)
- Groq API key (free at [console.groq.com](https://console.groq.com))
